# Requisitos Funcionais

## RF001

O sistema deve permitir acesso à página inicial.

## RF002

O sistema deve permitir abertura do modal de login.

## RF003

O sistema deve permitir autenticação com credenciais válidas.

## RF004

O sistema deve permitir adicionar produtos ao carrinho.

## RF005

O sistema deve permitir remover produtos do carrinho.

## RF006

O sistema deve permitir finalizar compras.
