# Relatórios

O framework utiliza Extent Reports.

## Recursos

* Registro de execução
* Logs de informação
* Logs de sucesso
* Registro de falhas
* Anexação de screenshots

## Local

```text
target/extent-report.html
```

## Eventos

### INFO

Passos executados durante o cenário.

### PASS

Validações aprovadas.

### FAIL

Falhas encontradas durante a execução.
